# 누수닥터 PRO 2.0 Android

This Android WebView app opens https://rlgnsekf-ux.github.io/leakdoctor-pro/.

Upload the **contents** of this ZIP into the root of a new GitHub repository (not inside a subfolder). Go to Actions > Build LeakDoctor PRO APK > Run workflow. Download the APK from Artifacts after a successful run.

The app needs an internet connection. The website's actual UI/version is controlled by the deployed web page, not by the Android wrapper. This is a debug APK; do not use it for public Play Store release. The APK is not yet build-tested.
