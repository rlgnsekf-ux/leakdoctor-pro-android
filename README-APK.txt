LeakDoctor PRO Android APK project
Upload all extracted files and folders to the ROOT of https://github.com/rlgnsekf-ux/leakdoctor-pro
Replace .github/workflows/build-apk.yml with the included version.
GitHub Actions -> Build LeakDoctor APK -> Run workflow, then download the artifact ZIP and extract APK.
This is a DEBUG-signed test build. It loads the existing GitHub Pages website, so internet is required.
Camera/OCR must be tested on the device. Never use pressure-drop readings alone as a definitive leak diagnosis.
